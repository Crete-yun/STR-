# STR混合DNA样本多人身份鉴定系统

## 项目简介

本项目来源于数学建模竞赛题目，针对法医物证领域中混合DNA样本的多人身份鉴定问题展开研究。项目基于STR（Short Tandem Repeat，短串联重复序列）分型数据，利用Python构建完整的数据分析与建模流程，实现混合样本贡献者人数预测、DNA贡献比例估计以及贡献者身份匹配等功能。

项目由本人独立完成，并获得校级奖项。

---

## 项目目标

针对混合DNA检材分析中的关键问题，完成以下任务：

* 混合样本贡献者人数预测
* DNA贡献比例估计
* 候选贡献者身份匹配
* STR峰高数据分析与特征提取

## 主要功能

### 1. 数据预处理

* 缺失值处理
* 异常值检测
* 数据标准化
* STR峰高信息提取

### 2. 特征工程

提取多种反映样本特征的信息，包括：

* 峰高统计特征
* 等位基因数量特征
* 基因座分布特征
* 样本复杂度特征

### 3. 贡献者人数预测

基于机器学习方法建立分类模型，对混合DNA样本中的贡献者人数进行预测。

采用模型包括：

* Random Forest
* SVM
* XGBoost
* MLP

### 4. DNA贡献比例估计

结合峰高信息构建贡献比例估计模型，计算各贡献者在混合样本中的DNA占比。

### 5. 身份匹配分析

通过候选个体组合搜索与基因型匹配分析，筛选最可能的贡献者组合，实现身份识别。
